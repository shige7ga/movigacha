# ムビガチャ

「今日、何の映画観る？」を解決する映画ガチャ提案アプリ。

ボタンを押すだけで映画をランダムに1本提案します。  
分類・カテゴリ・気分で絞り込むことも可能。

デプロイ先：https://movigacha.onrender.com/

## 作成背景

- 「選択肢が多すぎて決められない」という映画選びの悩みを解決したかった
- いつも選ぶ映画が自分の好みに偏ってしまう。普段見ないジャンルや作品との偶然の出会いを楽しめるようにしたかった
- Claude Code を使った AI エージェントでのコーディングのみで開発を実施することで、バイブコーディングの流れを検証するため

## 技術スタック

- Ruby 3.3
- Ruby on Rails 7.2
- PostgreSQL
- Tailwind CSS
- Docker / Docker Compose
- Render / Neon

## ローカル起動手順

### 必要なもの

- Docker
- Docker Compose

### 手順

```bash
# 1. リポジトリをクローン
git clone git@github.com:shige7ga/movigacha.git
cd movigacha

# 2. 起動（初回はイメージビルドあり）
docker compose up --build

# 3. ブラウザで開く
open http://localhost:3000
```

初回起動時に自動で `db:migrate` と `db:seed`（112件の映画データ）が実行されます。

### seedデータのリセット

```bash
docker compose exec web bundle exec rails db:seed
```

## 工夫した点

- 「ガチャを回す」ボタンを画面の中心に置くことで、どういった機能か一目でわかるようにした
- 一つの画面で完結するシンプルなデザインとした
- フィルター（分類・カテゴリ・気分）を常時表示することで、条件を変えながら連続してガチャを楽しめる設計にした
- 映画データを複数の軸（分類・カテゴリ・気分）で分類することで、絞り込みの組み合わせによる多彩なガチャ体験を実現した
- 結果画面からワンクリックで再びガチャを回せるようにし、気に入らない場合もストレスなく次の提案を受けられるようにした

## 今後の改善

## 画面構成

- `/` — ガチャトップ（ボタン＋任意の絞り込み：分類・カテゴリ・気分）
- `/result` — ガチャ結果表示
